# Contract Deployment Guide — Midnight Preprod

This guide walks you through deploying `counter.compact` to the Midnight Preprod testnet.

---

## Prerequisites Checklist

- [ ] **Node.js 22+** — `node --version`
- [ ] **Lace wallet** with Midnight support enabled
- [ ] **tNIGHT tokens** on Preprod (from faucet)
- [ ] **tDUST tokens** generated (via delegation in Lace)
- [ ] **Compact compiler** (`compact` CLI) — for generating ZK circuit keys

---

## Step 1 — Get tNIGHT from the Faucet

1. Open **Lace** → Switch to **Preprod** network
2. Copy your **Unshielded address** (starts with `mn1...`)
3. Visit the faucet: **https://midnight-tmnight-preprod.nethermind.dev/**
4. Paste your address and request tNIGHT
5. Wait ~2 minutes for confirmation

---

## Step 2 — Generate tDUST (transaction fee token)

tDUST is required to pay for Midnight transactions. It's generated by delegating tNIGHT.

1. In Lace → Go to **Staking** section
2. Delegate your tNIGHT to any active pool
3. tDUST will start accumulating automatically
4. Wait at least **5 epochs** (~1–2 hours on Preprod) before deploying

---

## Step 3 — Install Compact Compiler (for ZK circuit keys)

> **Windows users must use WSL** for this step.

```bash
# In WSL or Linux terminal:
curl --proto '=https' --tlsv1.2 -LsSf \
  https://github.com/midnightntwrk/compact/releases/latest/download/compact-installer.sh | sh

# Verify:
compact --version
```

Then compile the contract:

```bash
cd risein1
compact compile contract/src/counter.compact contract/managed/counter
```

This generates the ZK circuit keys in `contract/managed/counter/`.

---

## Step 4 — Set Up Deployment Config

```bash
cd deploy
cp .env.example .env
```

Edit `deploy/.env`:
```env
# Get your seed from Lace: Settings → Security → Export seed
MIDNIGHT_SEED=your_24_word_mnemonic_or_64_hex_seed

MIDNIGHT_NETWORK_ID=preprod
MIDNIGHT_INDEXER_URI=https://indexer.testnet-02.midnight.network/api/v1/graphql
MIDNIGHT_PROOF_SERVER_URI=https://proof-server.testnet-02.midnight.network
```

> ⚠️ **Security:** `deploy/.env` is in `.gitignore` — never commit your seed phrase!

---

```bash
cd deploy
npm install
node src/deploy.mjs
```

## Step 6 — Verify on Explorer

After deployment, your contract address will be saved to `deploy/deployment.json`.

Visit the Midnight Preprod explorer to verify:
```
https://explorer.testnet-02.midnight.network/contracts/<YOUR_ADDRESS>
```

You should see:
- Contract creation transaction
- Initial state: `yes_count=0`, `no_count=0`, `total_votes=0`

---

## Step 7 — Update Frontend

The deploy script automatically updates `frontend/.env`. If you need to do it manually:

```bash
# Edit frontend/.env
VITE_CONTRACT_ADDRESS=mn1abc123...xyz789

# Rebuild frontend
cd frontend
npm run build
```

Then redeploy to Vercel:
```bash
vercel --prod
```

## Alternative: Using create-mn-app

If you want a fully automated deployment experience:

```bash
# Select "Contract" template
npm run setup -- --network preprod
```

## Troubleshooting

### "Wallet.InsufficientFunds"
- You need more tDUST. Wait longer after delegation, or request more tNIGHT from faucet.

### "Proof server connection refused"
- The Midnight public proof server may have rate limits.
- Try running a local proof server via Docker:
  ```bash
  docker run -p 6300:6300 midnightntwrk/proof-server:latest
  ```
  Then set `MIDNIGHT_PROOF_SERVER_URI=http://localhost:6300`

### "compactc: command not found" / "compact: command not found"
- Use WSL on Windows
- Re-run the installer and restart your terminal

### Transaction timeout
- Preprod can be slow. Wait longer and check the explorer for pending transactions.
